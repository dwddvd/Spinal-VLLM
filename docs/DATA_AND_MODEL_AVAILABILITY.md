# Data and model availability

## Data

The human MRI data are not publicly redistributed because the source images and annotations
are governed by institutional ethics, privacy, and data-use restrictions. Qualified research
requests may be considered through the corresponding author and the responsible institution,
subject to institutional and ethics review and execution of an appropriate data-use agreement.
The public code does not contain patient data or a reversible patient mapping.

## Trained weights

The LoRA adapters, nnU-Net checkpoints, and YOLO checkpoints used in the study are not included
in the public repository. These files were trained on restricted human imaging data; public
release would require a separate privacy, memorization-risk, institutional, and upstream-license
review. The repository instead provides the training, inference, aggregation, and statistical
analysis code together with the executed software versions and parameter settings.

## Base models

Qwen and Ultralytics base-model files are governed by their respective upstream licenses and
must be obtained from their official distribution channels.
